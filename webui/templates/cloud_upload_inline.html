The collector script for the chosen platform reads these lists and writes the bundle. Run it where the provider's command line is signed in, the provider's Cloud Shell is the easiest place, with read access only.
AWS: one JSON object with the keys Vpcs, Subnets, RouteTables, SecurityGroups, NetworkAcls and NetworkInterfaces (optionally PrefixLists and PrefixListEntries), each holding the list the matching describe command of the AWS CLI prints. Azure: one JSON object with the keys virtualNetworks, networkSecurityGroups, applicationSecurityGroups, networkInterfaces and routeTables, each holding the list the ARM API returns for the subscription. Google Cloud: one JSON object with the keys networks, subnetworks, firewalls, networkFirewallPolicies, instances and routes (optionally firewallPolicies, addressGroups and instanceTags), each holding the list the matching gcloud list command prints as JSON.
